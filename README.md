## Folder contents
Each project folder will contain:
- `main.py` — Python source code
- `README.md` — problem statement, objectives, assumptions, and conclusion
- `algorithm.md` — step-by-step algorithm
- `pseudocode.md` — pseudocode
- `flowchart.md` — flowchart in Mermaid format
- `test_cases.md` — test cases and expected outputs
- `output/` — screenshots of program runs

## How to run
1. Install Python 3.
2. Open a terminal in the chosen project folder.
3. Run `python main.py`.

## Syllabus alignment
The projects are designed around the topics listed in Units I–III of the provided MID-1 Python syllabus. They avoid classes, inheritance, databases, and file handling.
