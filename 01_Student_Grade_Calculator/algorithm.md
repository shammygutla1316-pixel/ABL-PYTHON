# Algorithm

1. Start.
2. Input student name and marks for three subjects.
3. Check whether each mark is between 0 and 100.
4. If any mark is invalid, display an error message.
5. Otherwise, calculate total and average.
6. Assign a grade using an if-elif-else ladder.
7. Display the student's name, total, average, and grade.
8. Display PASS if average is at least 40; otherwise display FAIL.
9. Stop.
