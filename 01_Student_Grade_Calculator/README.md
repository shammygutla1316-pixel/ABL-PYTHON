# Project 1: Student Marks and Grade Calculator

## Problem statement
Accept a student's name and marks in three subjects, calculate the total and average, assign a grade, and display pass/fail status.

## Objectives
- Practise input/output and type conversion.
- Calculate totals and averages using arithmetic operators.
- Apply an `if-elif-else` ladder.
- Validate marks before calculating.

## Assumptions
- Three subjects, each marked out of 100.
- The average determines the grade.
- Grade boundaries used here are illustrative: A ≥ 90, B ≥ 80, C ≥ 70, D ≥ 60, E ≥ 40, otherwise F.
- Change grade boundaries if your faculty provides different rules.

## Concepts
Variables, `input()`, `float()`, arithmetic, relational and logical operators, formatted output, and conditional statements.

## How to run
Run `python main.py` in this folder.

## Conclusion
This program demonstrates basic calculations and decision-making in Python.
