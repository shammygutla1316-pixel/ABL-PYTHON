# Test Cases — Student Attendance Calculator

Test the program in Python 3. Outputs below are expected output summaries; prompts and formatting may vary slightly by console.

1. **Input:** `100 / 80`  
   **Expected output:** Attendance: 80.00%; Status: Eligible

2. **Input:** `100 / 75`  
   **Expected output:** Attendance: 75.00%; Status: Eligible

3. **Input:** `100 / 60`  
   **Expected output:** Attendance: 60.00%; Status: Shortage

4. **Input:** `0 / 0`  
   **Expected output:** Total classes held must be positive.

5. **Input:** `10 / 12`  
   **Expected output:** Attended classes must be between 0 and total classes.
