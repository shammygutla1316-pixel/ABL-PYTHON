# Personal Portfolio Website

## Problem Statement
Create a personal webpage displaying profile, education, skills, hobbies, projects and contact details.

## Objectives
- Organize personal information using HTML sections.
- Use headings, paragraphs, lists and anchor links.
- Apply CSS text, color, background, margin, padding and border properties.
- Make the layout suitable for narrow screens.

## Assumptions
All names, education and contact details are sample details. Replace them before submission.

## Algorithm
1. Create the HTML document and connect style.css.
2. Add header and navigation links.
3. Create About, Education, Skills, Hobbies, Projects and Contact sections.
4. Apply CSS properties and a small-screen media rule.
5. Open index.html and test the navigation links.

## Syllabus Topics
HTML structure/elements, class attribute, anchor element, lists, CSS syntax, text/background color, font family/size, margin, padding, border, box model and viewport.
