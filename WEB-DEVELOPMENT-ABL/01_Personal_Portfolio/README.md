# Personal Portfolio Website

## Problem Statement
Create a personal webpage to show a profile, education, technical skills, hobbies, projects and contact details.

## Objectives
- Create a clear personal profile using HTML elements.
- Use headings, paragraphs, lists and hyperlinks.
- Apply CSS text, color, background, margin, padding and border properties.
- Make the page easier to view on a small screen.

## Assumptions
The name, college, skills and contact details are sample details. Replace them with your own details before submission.

## Algorithm
1. Start the HTML document.
2. Add a header and navigation links.
3. Create About, Education, Skills, Hobbies, Projects and Contact sections.
4. Link the CSS file.
5. Apply colors, spacing, borders and a mobile-width rule.
6. Save and open index.html in a browser.

## Syllabus Topics Used
HTML structure and elements, class attribute, anchor element, lists, CSS syntax, text color, background color, font family, font size, margin, padding, border, box model and viewport.
