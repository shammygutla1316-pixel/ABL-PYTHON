# Tourism and Heritage Website

## Problem Statement
Introduce tourism destinations, cultural heritage, local cuisine and travel tips.

## Objectives
- Present destinations in separate cards.
- Use headings, paragraphs, ordered and unordered lists.
- Add navigation links to page sections.
- Apply CSS colors, backgrounds, borders and spacing.
- Adjust the cards for narrow screens.

## Assumptions
This is an educational sample about Andhra Pradesh.

## Algorithm
1. Create the HTML document and link style.css.
2. Add the website title and navigation links.
3. Create a hero section and destination cards.
4. Add culture, food and travel-tip sections.
5. Style the page using CSS.
6. Open the page and test all navigation links.

## Syllabus Topics
HTML structure/elements, class attribute, anchor element, ordered and unordered lists, CSS syntax, text/background color, font family/size, margin, padding, border, box model and viewport.
