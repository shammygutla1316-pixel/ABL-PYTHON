# Tourism and Heritage Website

## Problem Statement
Create a tourism webpage that introduces destinations, cultural heritage, local cuisine and travel tips.

## Objectives
- Present destination information in separate cards.
- Use headings, paragraphs, ordered and unordered lists.
- Add navigation links to page sections.
- Use CSS colors, backgrounds, borders and spacing.
- Adjust the cards for narrow screens.

## Assumptions
The webpage is an educational sample about Andhra Pradesh. Destination descriptions are short introductory text.

## Algorithm
1. Create the HTML document and link the CSS file.
2. Add the website title and navigation links.
3. Create a hero section.
4. Add destination cards.
5. Add culture, food and travel-tip sections.
6. Style the page using CSS.
7. Open the page and test all navigation links.

## Syllabus Topics Used
HTML structure and elements, class attribute, anchor element, ordered and unordered lists, CSS syntax, text color, background color, font family, font size, margin, padding, border, box model and viewport.
