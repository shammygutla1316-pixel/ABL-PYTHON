# Web Development Activity-Based Learning – 3 Easy Case Studies

Selected from the official Web Development ABL task sheet:
1. Case Study 1 – Personal Portfolio Website
2. Case Study 2 – College Information and Admissions Website
3. Case Study 17 – Tourism and Heritage Information Website

All projects use HTML and CSS only, staying within the supplied syllabus topics: HTML structure and elements, headings, paragraphs, lists, anchors, CSS syntax and rules, text and background colors, font properties, box model, margin, padding, borders, viewport and responsive layout.

Each project folder contains index.html, style.css, README.md, test_cases.md and an output folder. Replace sample names and contact details with your own before submission.
