# Web Development ABL – 3 Easy Case Studies

Selected from the official task sheet:
1. Case Study 1 – Personal Portfolio Website
2. Case Study 2 – College Information and Admissions Website
3. Case Study 17 – Tourism and Heritage Information Website

Each project uses HTML and CSS only. The code uses syllabus topics such as HTML structure and elements, headings, paragraphs, lists, anchors, CSS rules, text and background colors, font properties, margin, padding, borders, box model, viewport and responsive layout. No JavaScript or frameworks are used.

Each project contains index.html, style.css, README.md and test_cases.md.
